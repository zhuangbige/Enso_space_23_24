# Data Source And Citation Log

This log records both **literature sources** and **data sources**. Reports should
cite literature for interpretation and cite dataset pages/URLs for every plotted
or tabulated data product.

Access date for the initial search below: 2026-05-23.

## Logging Rule For Future Work

When a script downloads, subsets, or reads remote data, append a row with:

- date;
- dataset name;
- official documentation URL;
- exact access URL or API endpoint;
- variables and time range;
- local output file path;
- any caveat, such as authentication, chunking, missing months, or fallback use.
