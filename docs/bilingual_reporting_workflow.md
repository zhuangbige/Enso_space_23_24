# Bilingual Reporting Workflow

From this point onward, maintain both:

- concise English technical notes for scripts and reproducibility
- Chinese stage reports for research interpretation and presentation

Primary Chinese report:

```text
reports/阶段性中文报告.md
```

When major tables or figures are added, update the Chinese report with:

1. What was added.
2. Which source data were used.
3. Key numerical results.
4. Whether the result is reproduction, independent validation, or new research.
5. The next research action.

Current stage labels:

- 复现：running article Zenodo code and tables.
- 独立验证：recomputing article claims from raw public products.
- 研究阶段：seasonal decomposition, external-basin diagnostics, and mechanism tests.
