# ENSO经向OHC配置：成对高杠杆与正暖异常敏感性诊断

## 主要结果

- 原始有符号指标模型：partial r = -0.793，beta_D = -3.086，p = 0.0021。
- 同时删除1997和2015：partial r = -0.352，beta_D = -0.785，p = 0.3182。
- 78种leave-two-events-out：partial r范围 -0.902 至 -0.352，中位数 -0.801；100.0% 为负。
- positive-only指标并控制positive-only三纬带平均：partial r = -0.796，beta_D+ = -3.135，p = 0.0019。
- positive-only指标同时删除1997和2015：partial r = -0.389，beta_D+ = -0.872，p = 0.2668。
