# SODA3五日OHC—风应力转变检验：13个暖事件

## 预注册式设定

- 海洋指标：3—4月最大15日平均0—300米OHC距平，5°S—5°N、180°—140°W。
- 大气指标：5—6月最大15日平均实际纬向风应力，同一区域；正值为实际西风应力。
- 独立样本是13个事件，不把五日时次当作独立样本。
- 比较普通线性模型与连续分段线性模型；分段模型的转折点在每个训练样本中重新选择，使用嵌套留一事件验证。

## 核心统计

- Pearson相关：r = 0.738；参数p = 0.0040；事件置换p = 0.0087。
- Spearman相关：ρ = 0.599，p = 0.0306。
- Pearson bootstrap 95%区间：0.051至0.933。
- 删除1997年后相关：r = 0.397；逐事件删除后的相关范围为0.397至0.823。
- 线性模型LOEO RMSE：0.0096 N m⁻²。
- 嵌套分段模型LOEO RMSE：0.0097 N m⁻²，相对线性模型改善-0.5% 。
- 最优候选转折点：+0.656 GJ m⁻²；bootstrap 90%区间为+0.152至+1.418 GJ m⁻²。

## 判断

分段阈值未通过预设稳定性检验，因此不报告普适数值阈值；更稳妥的表述是春季中太平洋OHC构成一个连续的海洋检查点。

只有1997年在5—6月出现了连续两个候的实际西风应力。2015年虽然春季OHC峰值达到+1.60 GJ m⁻²，风应力仍未转正；删除1997年后相关降至r = 0.397。这说明OHC可以描述海洋为耦合准备到什么程度，但仅凭OHC还不能可靠预测大气一定会接上。当前样本也不足以对“是否出现实际西风”拟合二元阈值，因为13个事件中只有一个正例。

这项检验回答的是“春季海洋热状态能否区分随后风应力接上的强弱”，不是证明OHC直接造成西风。SODA3中的风应力是再分析系统采用的大气强迫场，并非独立于海洋分析的观测，因此任何稳定关系最终仍需用TAO等独立资料核对关键事件的日期。
