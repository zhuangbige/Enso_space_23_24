# ENSO类型转换下一步实验矩阵

本目录把观测资料中得到的候选路径转成可交给AGCM或耦合模式的预注册实验。当前已经完成设计、观测约束统计矩阵和P0规定SST强迫；Isca共同大气态正在积分。`ready_for_model`不表示对应集合已经完成。

## 审阅后保留的设计原则

- 把3—6月表述为春季转变窗口；四月只是逐月扫描中首次出现正技巧的候选切片，不定义为普适阈值。
- 不把降水、SLP、纬向风应力和WWB硬合成一个Atmospheric Gate Index。13事件不足以安全估计这类复合权重，而且把最终风响应放回预测量会造成循环定义。正式结果分别报告“对流—气压支路”“赤道风应力支路”和WWB/东北风桥梁。
- AGCM只能回答“给定SST后大气为什么接上”，不能关闭动力海洋门控。海洋门控失败和EP/CP翻型必须由耦合模式完成。
- 审阅意见提出的Ocean × Atmosphere × Background三因子思想被拆成顺序检验：P0 AGCM检验外海盆背景，P0耦合九格检验Ocean × Wind；只有九格出现稳定翻型后才加入NPMM × WWB。这样避免在小集合中一次估计过多高阶交互。

## 执行顺序

1. 先跑P0的四格AGCM矩阵：`Indo-Atlantic on/off × residual FEP on/off`。它回答在给定海温条件下，外海盆加热是否削弱FEP引起的降水—气压—风响应。
2. 再跑P0的九格耦合矩阵：`ocean gate low/neutral/high × wind regime adverse/neutral/favorable`。这是唯一直接检验“类型是否转换”的核心矩阵。
3. 如果九格矩阵出现稳定翻型，再跑P1的`NPMM × WWB`确认矩阵并改变三个WWB起始日，检查随机天气扰动是否只在特定背景态下有效。
4. `AG_NPMM0`和`AG_DIPOLE0`用于拆分NPMM与Jiang型经向降水偶极；它们不承担成熟类型的最终因果判定。

## 预先声明的判据

- EP一致：DJF E/C > 0且Niño3−Niño4 > 0。
- CP一致：DJF E/C < 0且Niño3−Niño4 < 0。
- 两指标符号不同：记为“类型定义不一致”，不宣布翻型。
- 稳健翻型：两指标同向过零，且集合95%区间不跨零。
- 海气“接上”必须同时报告降水、SLP和赤道纬向风应力三条支路，不能只用合成分数。
- Ocean gate failure不采用“把140°W以东温跃层钉死为气候态”的非平衡做法；低/高门控通过守恒盆地总热含量的东西再分配构造，并以Q20、D20、SSH和混合层收支共同验证。

## 当前观测矩阵告诉我们的边界

- NPMM×WWB和海洋门控×有利风场对MJJ接通的交互点估计为正，但事件bootstrap区间均跨零。
- `Indo-Atlantic × residual FEP`的留一事件技巧为负，不能把它当作稳定经验预测器。
- 九格观测矩阵没有任何格点使E/C与Niño3−Niño4同时、稳健地转成EP。
- 因此下一步的价值不在于重复相关，而在于用固定初值和成对强迫真正做因果对照。
- 全部78种留二事件检验中，降水偶极与综合大气响应的偏相关均为正，中位数为0.73，95%删除组合仍高于0.5；但同时删除1997和2015时降至0.33。因此该联系符号稳健，却仍受强事件杠杆影响。
- NMME加5—6月耦合的年代顺序RMSE为0.32°C，优于春季型态持续性0.73°C、春季Niño3.4-only 0.56°C和校准NMME 0.43°C。它应称为“春末观测更新”，不能称为纯3月预报技巧。

## P0强迫准备（2026-07-31）

- 已生成 `forcing/ersstv5_2023_agcm_ia_fep_factorial_mar_aug.nc`，覆盖
  2023年3—8月、2° ERSSTv5海温网格。
- `p0_agcm_run_manifest.csv`列出两套四格各30成员，共240个运行单元，
  包括SST变量名、积分时段、成员随机种子和必要的月/日输出。当前状态
  为`awaiting_target_model_and_compute`。
- `AG_IA0/1_FEP0/1` 是预注册的主四格：IA使用2023相对1982—2024
  逐月气候态的总异常，FEP使用与Niño3.4、E/C型态及趋势正交后的
  5°S—5°N、90°W—80°W残差空间足迹。
- 同一文件中的 `AG_IAR0/1_FEP0/1` 是机制敏感性四格：IA只保留移除
  趋势、Niño3.4和E/C型态后的独立残差。它用于判断结果究竟来自总外
  海盆状态，还是来自超出同期ENSO共同演变的外海盆部分。
- 两套四格的“两个因子都开”均逐格重构完整2023观测SST，误差为零；
  IA与FEP掩膜不重叠。文件是通用CF-NetCDF，实际送入CAM/ECHAM前仍
  需按目标模式网格重映射并补齐其海冰/陆地边界处理。
- 1982—2024全年份观测先验与图表见
  `../../reports/ENSO_P0_IA_FEP强迫与全年份观测先验.md`；它不替代
  AGCM动力积分。
- 全43年中IA×FEP交互不稳健；在23个MJJ Niño3.4为正的年份中，
  总异常和独立IA两种定义都给出负交互及留一年技巧改善，意味着外海盆
  暖背景可能削弱FEP向赤道西风支路的兑现。但所有年份bootstrap区间
  仍跨零，且TIO与TNA拆开后无法稳定指定单一主导海盆，所以这仍是
  P0四格要检验的假说，而不是观测定论。
