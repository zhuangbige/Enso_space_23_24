# 2023/24 El Nino Air-Sea Decoupling Attribution

This repository implements the first-stage research scaffold for diagnosing why the
2023/24 strong El Nino had strong oceanic warming but comparatively weak wind,
rainfall, and teleconnection responses.

中文阶段性报告：

The first stage is deliberately light: it organizes data sources, diagnostic targets,
and an AGCM experiment matrix. It does not download large climate datasets or run
AGCM experiments by default.

## Research Direction

Main question:

> From boreal summer 2023 through winter 2024, which ocean basins and background
> warming patterns weakened the usual atmospheric response to Pacific El Nino SST
> forcing?

The project starts with three diagnostic tracks:

- SST-wind-SOI regression residuals to quantify weak coupling.
- Seasonal decomposition for AMJ, JJA, SON, and DJF.
- Response diagnostics for u850, SLP/SOI, precipitation/OLR, 200 hPa velocity
  potential, and Walker circulation.

## Repository Layout

- `el_nino_decoupling/`: small tested helpers for data catalogs, experiment matrices,
  and index definitions.
- `scripts/`: command-line utilities that emit the data source table, AGCM matrix,
  and first-pass checklist.
- `docs/`: human-readable research direction, data catalog, experiment matrix, and
  diagnostic workflow.
- `tests/`: standard-library `unittest` tests.
