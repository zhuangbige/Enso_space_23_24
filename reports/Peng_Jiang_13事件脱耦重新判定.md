# Peng与Jiang方法下13次暖事件的海气脱耦重新判定

## 结论

在1982、1986、1991、1994、1997、2002、2004、2006、2009、2015、
2018、2019和2023这13个发展年中，**2023/24是唯一同时得到Peng式
全年风压响应和Jiang式发展季FEP—东北风—西风链条支持的明确脱耦
事件**。

2006/07和2018/19只表现为局部或阶段性候选：2006/07在成熟DJF出现
跨资料一致的弱风压响应，但其全年Peng响应和春夏Jiang链条均不弱；
2018/19只有SOI分支偏弱，风响应并未同步减弱。二者不能与2023/24
放在同一“明确脱耦”类别。

## 判定方法

### Peng式全年响应

使用Peng et al. (2025) Fig. 1的6月至次年1月平均量：Niño-3 SSTA、
CWP 10 m纬向风和SOI。按历史Niño-3—大气响应回归计算
observed/expected ratio。

论文没有给所有事件规定二元阈值。本项目为了进行保守筛选，要求：

1. Niño-3平均异常至少为+0.5°C，避免预期响应接近零时比值发散；
2. CWP u10和SOI两个响应比均不超过0.5。

该条件只由2023满足：u10响应比0.27，SOI响应比0.31。1997和2015
分别约为0.91/0.83和0.93/0.85，属于基本正常的强事件耦合。

### Jiang式发展季机制链

使用5—7月三个量。residual FEP先去除月别趋势和Niño3.4线性分量；
东北风与风应力响应再控制海温幅度、海温空间型态和趋势：

1. residual FEP SSTA；
2. 3°—7°N、180°—130°W的850 hPa异常东北风入侵；
3. 中西太平洋纬向风应力响应残差。

为汇总事件，本项目使用保守机制链筛选：residual FEP不低于+1 SD、
东北风入侵不低于+1 SD，同时纬向风应力响应不高于−0.75 SD。这不是
Jiang论文提出的正式事件分类阈值，而是把论文机制转为可重复事件筛选
的工作定义。

2023分别为+1.93、+1.39和−0.95 SD，是唯一满足完整链条的事件。
1997和2015虽然residual FEP分别达到+1.69和+1.03 SD，但东北风/风应力
分支不支持脱耦，说明FEP偏暖本身不足以造成弱耦合。

### FEP率先响应与FEP主导的区别

为描述1—4月先后顺序，另设一个比Jiang正式“FEP主导”更宽松的过程
诊断：2—4月至少连续两个月满足总FEP异常和residual FEP均为正，同时
Niño3.4尚未超过+0.2°C。满足者为1997、2002和2023，起始月份分别为
3月、2月和2月。

这只能称为“持续FEP率先响应”。按照Jiang论文对5—7月FEP幅度及
residual贡献的严格筛选，13个1980年后样本中只有2023属于FEP主导事件。
1997随后迅速建立强盆地耦合，2002的早期FEP信号没有持续主导，正好
说明FEP率先出现并不等于FEP最终主导，也不等于一定发生脱耦。

### 成熟季独立验证

以1982—2014年月别关系为基准，在控制Niño3.4幅度和SST空间型态后，
分别计算ERA5/GPCP综合残差和NCEP风压综合残差。两套产品DJF残差均
不高于−0.75 SD时，记为成熟季候选。

2023为−1.05和−0.83 SD，2006为−0.85和−0.77 SD。因此2006值得保留
为成熟季比较案例，但它不是Peng—Jiang共同支持的完整脱耦事件。

## 逐事件结论

| 事件 | 结论 | 理由 |
|---|---|---|
| 1982/83 | 无明显全年脱耦 | 春季局部响应偏弱，但Peng全年风压响应强，成熟期恢复并增强。 |
| 1986/87 | 无可靠判定 | Niño-3预测量偏小，Peng比值不稳定；没有Jiang机制链。 |
| 1991/92 | 无明显脱耦 | Peng风压响应高于预期，成熟季两套资料不弱。 |
| 1994/95 | 无明显脱耦 | Niño-3预测量小；中太平洋型的响应位置差异不能直接叫脱耦。 |
| 1997/98 | 强耦合参照 | FEP残差高，但西风、降水和成熟季响应都很强。 |
| 2002/03 | 无明显脱耦 | Peng和成熟季跨资料诊断均不支持持续弱响应。 |
| 2004/05 | 无明显脱耦 | 有东北风信号但无正residual FEP，且成熟期响应不弱，不构成Jiang链。 |
| 2006/07 | 成熟季候选 | DJF两套资料均偏弱，但Peng全年平均正常，发展季Jiang链不成立。 |
| 2009/10 | 发展季局部偏弱 | MJJ综合响应偏弱，但Peng全年响应接近预期，且不是FEP—东北风完整机制。 |
| 2015/16 | 强耦合参照 | residual FEP为正，但东北风异常方向相反，MJJ耦合非常强。 |
| 2018/19 | 单分支候选 | SOI响应比0.37，但u10响应比0.93，成熟季跨资料不支持全面脱耦。 |
| 2019/20 | 不纳入明确判定 | Niño-3平均仅约+0.22°C，预期大气响应接近零，响应比失去稳定意义。 |
| 2023/24 | **明确脱耦** | Peng两分支约为预期三成；Jiang机制链完整；DJF两套独立资料均位于弱响应端。 |

## 当前研究样本建议

- 主要脱耦事件：2023/24；
- 成熟季候选：2006/07；
- 单分支/阶段性候选：2009/10、2018/19；
- 强耦合对照：1997/98、2015/16，1982/83作为全年强耦合但春季有阶段差异的补充对照；
- 其余事件不作为脱耦样本；2019/20作为边缘暖状态单列。

后续研究应优先解释2023为何同时满足发展季Jiang链和成熟季Peng弱响应，
并用2006检验“成熟季内部变率型弱耦合”是否属于另一种机制。不要把所有
局部弱风年份合成一个脱耦组。
